# 桌面端开发中

这是 Rust + Tauri 本地客户端的开发版本，尚不能替代现有应用。可以配置 DeepSeek、读取网页标题和正文、生成摘要及最多三个标签，并保存在本地 SQLite。文章正文转换为 Markdown，保留代码、表格和图片，阅读器支持调整字体、字号、文字颜色和背景。MCP、CLI、备份和 WebDAV 均尚未实现。

文章中的 PNG、JPEG、GIF 和 WebP 图片会下载并与正文一起保存在 SQLite，离线阅读时从本地加载；音频和视频不保存。每篇最多保存 24 张图片，每张不超过 2 MiB，总计不超过 8 MiB。无法下载或不支持的图片会提示，阅读时显示占位说明。旧收藏可在阅读器中点击重新获取按钮，重新抓取正文和图片；抓取不完整时不会覆盖已有正文。

阅读位置按收藏分别保存在客户端本地的 WebView 存储中，切换文章、关闭阅读区或退出应用后再次打开会尝试恢复；清除应用的 WebView 数据会清除这些位置记录。

正文默认以阅读模式打开，可通过阅读区顶部的编辑图标切换到 Markdown 编辑模式，修改后保存或取消。保存只更新本地正文，原有图片和批注会保留；若其他操作已更改正文，会提示冲突以避免覆盖。编辑期间切换或关闭文章会提示未保存的修改。

在阅读器中选择正文或代码后点击右键，或在正文图片上点击右键，再选择「添加批注」，可添加带原文位置的批注。批注和创建、修改时间保存在 SQLite 中，可在文章底部修改或删除；侧栏「笔记」按文章分组并依原文位置排列，点击批注可定位原文。原文更新后如果无法可靠匹配，批注仍会保留并提示无法定位。旧的普通阅读笔记无需迁移操作，会继续显示。

图片下载只连接经过校验的公网地址。如果本机 DNS 返回代理软件使用的虚拟地址（198.18.0.0/15），客户端会通过 Google 公共 DNS 的 HTTPS 接口查询图片域名并校验结果，域名因此会发送给该服务；无法安全解析或连接的图片会跳过并提示。

收藏可标记为喜欢或归档，侧栏标签可多选，结果必须同时匹配全部选中标签及当前入口；再次点击标签取消筛选，切换入口时保留标签选择。首页和喜欢不包含归档收藏，归档入口显示已归档收藏。在标签旁点击「＋」可创建本地标签，并通过收藏的「编辑收藏」修改标题、简介和标签。无法获取正文的链接也可手工填写并保存；阅读页会提示打开原网页，并可由用户选择尝试重新获取正文。删除侧栏标签会将它从所有收藏中移除，不会删除收藏本身。手工标签不限数量；AI 只从已有标签中选择最多三个，没有合适标签则留空，不会自动创建新标签。搜索对当前入口和标签筛选范围内的标题、标签和正文做子串匹配；搜索归档内容时选择归档入口。阅读页可添加和删除本地笔记。状态、手工标签和笔记保存在 SQLite 中。

通过首页「＋」可选择收录链接或手写文章。手写文章无需网址，可填写标题、简介、标签及 Markdown 正文，也可通过「编辑收藏」继续修改；侧栏「笔记」同时展示手写文章和含阅读笔记的收藏。链接类型会按网址识别并保存，旧收藏会在数据库升级时保留并识别类型。

Windows 开发需要 Rust、Microsoft C++ Build Tools（包含 C++ 桌面开发和 Windows SDK）及 WebView2 Runtime。安装依赖后，在仓库根目录运行：

```sh
pnpm install
pnpm desktop:dev
```

数据库位于 Tauri 应用本地数据目录的 `trove.sqlite3`。此开发版本的数据格式尚未稳定，不应保存唯一副本。

在「AI 设置」中填写 DeepSeek 模型名称和 API Key 后保存。Key 保存在应用本地数据目录的 `.env.local` 中，配置页不会回显已有密钥；留空保存可保留原密钥。输入网址并移开焦点会自动解析，也可点击「解析网页」重试。解析时，网页标题、最多 18000 个字符的原始内容以及已有标签会发送给 DeepSeek。长度在此范围内的文章会请 AI 优化 Markdown，并校验文字、链接、图片、代码和表格是否保留；校验失败时使用本地转换结果。更长的文章完整保存在本地，但目前只使用前 18000 字生成摘要，不进行全文 AI 排版。未配置 AI 或调用失败时仍可保存本地转换后的正文。需要登录或依赖 JavaScript 渲染的页面可能无法读取，可手动填写并保存。

桌面端按网址识别技术形态：常规文章提取并保存正文；GitHub 和 GitLab.com 项目通过公开 API 读取默认分支 Markdown README，GitHub 用户读取公开简介和可用的 Profile README；YouTube、Bilibili 等视频站保存页面可读取的介绍。其他代码站保存页面公开简介。点击列表中的收藏会在右侧显示已保存内容；视频可通过「打开视频」跳转原网页，其他链接也可通过阅读区的图标打开原网页。旧收藏没有资料时可手动尝试重新获取。GitHub 公开 API 有匿名请求额度，私有仓库、缺少 README 或内容需登录时可能无法获取；此时会提示并尝试使用公开网页简介，仍可手工填写。
