# 桌面端开发中

这是 Rust + Tauri 本地客户端的初始骨架，尚不能替代现有应用。可以配置 DeepSeek、读取网页标题和正文、生成摘要及最多三个标签，并保存在本地 SQLite。点击收藏标题可以阅读已提取的正文，调整字体、字号、文字颜色和背景；旧收藏首次打开时会尝试重新抓取正文。图片等静态资源的离线保存、MCP、CLI、备份和 WebDAV 均尚未实现。

收藏可标记为喜欢或归档，侧栏支持按状态和标签筛选；在标签旁点击「＋」可创建本地标签，并通过收藏的「编辑标签」选择或输入标签。删除侧栏标签会将它从所有收藏中移除，不会删除收藏本身。手工标签不限数量；AI 只从已有标签中选择最多三个，没有合适标签则留空，不会自动创建新标签。搜索对本地标题、标签和已保存正文做子串匹配，包括归档收藏。旧收藏需先打开以抓取正文，之后正文才能参与搜索。阅读页可添加和删除本地笔记。状态、手工标签和笔记保存在 SQLite 中。

Windows 开发需要 Rust、Microsoft C++ Build Tools（包含 C++ 桌面开发和 Windows SDK）及 WebView2 Runtime。安装依赖后，在仓库根目录运行：

```sh
pnpm install
pnpm desktop:dev
```

数据库位于 Tauri 应用本地数据目录的 `trove.sqlite3`。此开发版本的数据格式尚未稳定，不应保存唯一副本。

在「AI 设置」中填写 DeepSeek 模型名称和 API Key 后保存。Key 保存在应用本地数据目录的 `.env.local` 中，配置页不会回显已有密钥；留空保存可保留原密钥。输入网址并移开焦点会自动解析，也可点击「解析网页」重试。解析时，网页标题、最多 18000 个字符的原始内容以及已有标签会发送给 DeepSeek。需要登录或依赖 JavaScript 渲染的页面可能无法读取，可手动填写并保存。

桌面端按网址识别技术形态：常规文章提取并保存正文；GitHub 项目通过公开 API 读取默认分支 README，GitHub 用户读取公开简介和可用的 Profile README；YouTube、Bilibili 等视频站保存页面可读取的介绍。其他代码站保存页面公开简介。点击仓库、用户或视频标题仍会通过系统浏览器打开原网站，点击「查看内容」可在客户端阅读保存的资料；旧收藏没有资料时会尝试重新获取。GitHub 公开 API 有匿名请求额度，私有仓库、缺少 README 或内容需登录时可能无法获取；此时会提示并尝试使用公开网页简介，仍可手工填写。
